# Shenzhen 3D 0.2.9

- Friends (Beta), on the Mac: cancelling a file now stops it on both computers.

## New in this version

### Friends (Beta)

- **Cancel stops the file on both computers.** On the Mac, when you cancel a file you're sending or receiving, your friend's computer now stops too, and the file shows as cancelled on both sides. On Windows, Linux, Android, iPhone and iPad, Cancel already worked this way.

## Updating

- **Mac, Windows, Linux and Android.** Shenzhen 3D finds this update by itself and asks before installing it. With the Linux `.deb` or `.rpm`, it tells you the update is out and **Download** gets it for you to install.
- **iPhone and iPad.** Shenzhen 3D tells you when a new version is out. It installs only on the iPhones and iPads registered for testing.

## Downloads

- **Mac** (Apple Silicon, macOS 13 or later): `Shenzhen-3D-0.2.9-Apple-Silicon.dmg`. Open it and drag Shenzhen 3D into Applications.
- **Windows** (x64): `Shenzhen-3D-0.2.9-Windows-x64-Setup.exe`, or the `.msi`. They are not signed, so Windows may warn you before it installs them.
- **Linux** (ARM64): the `.AppImage`, `.deb` or `.rpm`.
- **Android** (ARM64): `shenzhen-3d-0.2.9-android-arm64-development.apk` installs directly; Android asks you to allow apps from this source first. The `.aab` is for publishing to a store and is not signed.
- **iPhone and iPad**: `shenzhen-3d-0.2.9-ios-registered-devices.ipa` installs only on the devices registered for testing. `shenzhen-3d-0.2.9-ios-arm64-simulator.tar.gz` runs in Xcode's iOS Simulator.
- **Browser**: unzip `shenzhen-3d-0.2.9-web.zip` and serve the folder over HTTP or HTTPS.

Friends (Beta) is in every version except the browser one.

`SHA256SUMS.txt` lists the SHA-256 of every file here.
