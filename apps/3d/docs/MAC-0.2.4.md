# Shenzhen 3D 0.2.4

- **Thin markings render cleanly:** printed text and labels on parts stay sharp at every zoom.
- **Friends (Beta): # starts with the open model,** and paste attaches files and pictures.
- **Windows:** the window keeps its size, Friends always starts, and people nearby can find your PC.
- **Android:** no red error message after an update.

## Viewing

- **Thin markings render cleanly.** Printed text, labels and silkscreen that sit just above a face, and faces that lie exactly on one another, no longer come out torn or flickering. They stay clean at every zoom and from every angle.

## Friends (Beta)

- **# starts with the open model.** Type **#** in a message: the open model comes first, marked **Current**. Keep typing to narrow the list, then press Return to attach. While the list is open, Return never sends the message, and "No matching files" says when nothing matches.
- **Paste to attach.** Pasting into a message (⌘V, or Ctrl+V) attaches copied files and pictures, such as a screenshot. Text still pastes as text.
- **Back to the end when you send.** Sending a message takes the chat to the end. If new messages arrive while you have scrolled up, a **New message ↓** button takes you to them.
- **Mac: messages save on macOS 15 and earlier.** On those versions of macOS, Friends could not save messages, so sending and receiving failed. They work now.

## Windows

- **The window keeps its size.** It opens at the size and place you left it. A window that got shorter each time you opened it is back to its full height.
- **Opening Shenzhen 3D again** while it runs brings its window forward, restored if it was minimized.
- **Friends always starts.** If security software such as Microsoft Defender removed part of Friends, Friends puts it back and starts. If Friends still can't start, it says why and what to do, instead of showing "Starting Friends…" without end.
- **People nearby can find your PC.** The installer asks Windows once to let people nearby find this PC on private networks. If they still can't, **Nearby** says what to change, with a button that takes you there.
- **Shortcuts say Ctrl,** such as Ctrl+O, instead of ⌘.

## Linux

- **Shortcuts say Ctrl,** such as Ctrl+O, instead of ⌘.

## Android

- **No red error after an update.** The first launch after an update, or after Android reopens the app, no longer shows an error message in red.
- **Shortcuts** show only once you use a keyboard, and say Ctrl instead of ⌘.

## Updating

- **Mac, Windows, Linux and Android.** Shenzhen 3D 0.2.3 finds this update by itself and asks before installing it. With the Linux `.deb` or `.rpm`, it tells you the update is out and **Download** gets it for you to install.
- **iPhone and iPad.** Shenzhen 3D 0.2.3 tells you when a new version is out. It installs only on the iPhones and iPads registered for testing.

## Downloads

- **Mac** (Apple Silicon, macOS 13 or later): `Shenzhen-3D-0.2.4-Apple-Silicon.dmg`. Open it and drag Shenzhen 3D into Applications.
- **Windows** (x64): `Shenzhen-3D-0.2.4-Windows-x64-Setup.exe`, or the `.msi`. They are not signed, so Windows may warn you before it installs them.
- **Linux** (ARM64): the `.AppImage`, `.deb` or `.rpm`.
- **Android** (ARM64): `shenzhen-3d-0.2.4-android-arm64-development.apk` installs directly; Android asks you to allow apps from this source first. The `.aab` is for publishing to a store and is not signed.
- **iPhone and iPad**: `shenzhen-3d-0.2.4-ios-registered-devices.ipa` installs only on the devices registered for testing. `shenzhen-3d-0.2.4-ios-arm64-simulator.tar.gz` runs in Xcode's iOS Simulator.
- **Browser**: unzip `shenzhen-3d-0.2.4-web.zip` and serve the folder over HTTP or HTTPS.

Friends (Beta) is in every version except the browser one.
