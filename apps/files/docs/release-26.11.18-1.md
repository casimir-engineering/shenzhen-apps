# Shenzhen Files 26.11.18-1

- Friends (Beta): Cancel works every time, and stops the file on both computers.
- Friends (Beta): a file you accept stays in view while it arrives.

## New in this version

- **Cancel works every time.** Clicking Cancel on a file that's arriving or being sent was sometimes missed while the progress was moving. It now cancels on the first click.
- **Cancel stops the file on both computers.** When you cancel, your friend's computer now stops too, and the file shows as cancelled on both sides.
- **The file you accept stays in view.** In a long chat, accepting a file could leave its progress below the bottom of the chat, so you had to scroll down to see it or to cancel it. The chat now stays at the end while the file arrives, until you scroll up yourself.

## Updating

Shenzhen Files updates itself as before: it checks once a day, or when you choose **Check for Updates…** in the app menu.
