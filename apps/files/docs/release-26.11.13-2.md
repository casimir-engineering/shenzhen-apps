# Shenzhen Files 26.11.13-2

- Starring a file no longer quits Shenzhen Files.

## New in this version

- **Starring a file no longer quits the app.** Clicking a file's star, to add it to Starred or to remove it, closed Shenzhen Files. It now stars the file and stays open.

## Updating

Shenzhen Files updates itself as before: it checks once a day, or when you choose **Check for Updates…** in the app menu.
