# Shenzhen Files 26.10.29-1

- **Friends (Beta): # starts with your selected files,** and ⌘V attaches copied files and pictures.
- **Friends chats go to the end when you send,** with a **New message ↓** button for what arrives while you read.
- **Friends messages save on macOS 15 and earlier.**

## Friends (Beta)

- **# starts with your selection.** Type **#** in a message: the files selected in the front window come first, marked **Current**, then the folder's other files. Keep typing to narrow the list, then press Return to attach. While the list is open, Return never sends the message, and "No matching files" says when nothing matches.
- **Paste to attach.** ⌘V in a message attaches files copied in Finder and pictures, such as a screenshot. Text still pastes as text.
- **Back to the end when you send.** Sending a message takes the chat to the end. If new messages arrive while you have scrolled up, a **New message ↓** button takes you to them.
- **Messages save on macOS 15 and earlier.** On those versions of macOS, Friends could not save messages, so sending and receiving failed. They work now.

## Updating

Shenzhen Files updates itself as before: it checks once a day, or when you choose **Check for Updates…** in the app menu.
