# Shenzhen Files 26.11.13-1

- Applications is in the sidebar, under Desktop.
- Friends (Beta): Shenzhen Files no longer quits when you copy your Friends ID.
- From the next update on, your windows and tabs come back after Shenzhen Files updates itself.

## New in this version

### Sidebar

- **Applications.** The sidebar has an Applications entry under Desktop that opens your Applications folder. If Applications was already among your bookmarks, it is now listed once, under Desktop.

### Updates

- **Your tabs come back after an update.** Until now, Shenzhen Files opened a single Home window after it updated itself. From this version on it reopens the windows and tabs you had open, with the same tab selected. You will see this the next time it updates. A tab that showed search results, or a folder that is no longer there, isn't reopened.

### Friends (Beta)

- **Copying your Friends ID no longer quits the app.** Clicking the copy button next to your Friends ID closed Shenzhen Files. It now copies the ID and shows "Copied". The same problem is fixed in the other places it happened: copying a link, changing your name, and a message that couldn't be sent.

## Updating

Shenzhen Files updates itself as before: it checks once a day, or when you choose **Check for Updates…** in the app menu.
