# Shenzhen Files 26.8.27-1

- Finder copies now paste the original file instead of its preview PNG, including files copied from read-only locations.
- Deleted local files now move into the real macOS system Trash and appear in Finder's Trash window.
- Added **Edit ▸ Delete Permanently…** with **Cmd-Shift-Backspace** and an explicit destructive confirmation.
- Added a polished folder-first macOS app icon with a contained white **深圳** signature.

The release is Developer ID signed and notarized. Shenzhen Files verifies the downloaded update's Developer ID, Team ID, bundle identifier, hardened runtime, notarization, and GitHub-provided SHA-256 digest before installing it.
