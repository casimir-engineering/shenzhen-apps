## Scope

Sources read, in order: `portable/docs/releases/*.md` (26.7.17-1 … 26.9.2-1),
the tagged release commit bodies and the untagged `Release …` commits,
`readme.md`, `portable/docs/release-notes-next.md`, and for the wave the eight
merge commits' own bodies plus `windows-markdown-design.md`,
`windows-launch-performance.md` and `windows-captures/`. **`docs/releasenotes.txt`
is SumatraPDF's changelog (0.1 → 3.6) and is out of scope**:
`windows-port-handoff.md` §1.1 establishes that the inherited `src/` tree is a
different application with a different document engine and zero references to
`shenzhen_pdf_core`, so none of its features (DDE, browser plugin, IFilter, CHM,
manga mode, …) are ShenzhenPDF features and none are audited here. Do not
re-ask.
