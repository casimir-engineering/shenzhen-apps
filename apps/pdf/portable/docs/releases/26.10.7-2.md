- Create an empty group from the + menu, then open documents into it.
- More reliable chapter controls and document search after leaving a panel filter.
- Consistent search fields, complete placeholders, and sharper vector icons when resizing panels.

---

## Reading and organization

- The tab-strip **+** opens a menu with **New Tab** and **New Group…**. Creating an empty group keeps the current document visible; the next documents you open go into that group. Empty groups and their next-open destination survive relaunch.
- Empty groups support names, colors, visibility, closing, and dropping documents into them. They appear in group management and the all-groups picker.
- Chapter expand/collapse controls respond across their full button area, including individual disclosures and the all-chapters toggle. Chapters uses the same outlined expand/collapse icon as Groups.

## Search and interface fixes

- Escape from a Chapters, Comments, or Groups filter clears the filter and returns focus to the document. Typing immediately afterward starts a fresh document search.
- Document-search failures now appear in the Search panel instead of looking like zero matches. Press Enter to retry a failed background read; invalid regular expressions also show an error.
- Chapters, Comments, Groups, and document Search share rounded search fields with matching font size, height, and spacing. Long queries still scroll horizontally.
- Empty search fields use the space left by the hidden clear button. Native text-layer clipping is corrected, so the Groups placeholder shows complete words, including “docs.” Typing still leaves space for the clear button.
- Interface icons use vector sources with fixed proportions. Native buttons redraw after resizing and display-scale changes without waiting for hover, and sidebar targets align to screen pixels. Toolbar tinting no longer creates a size-specific image, and OCR/translation fallback icons use vector drawing handlers.

## AI and saved workspaces

- AI group listing, updating, and moving tabs recognize empty groups. Empty groups also persist through YAML session round trips, including the destination for subsequently opened documents.
- Existing document rendering, Collection contents, and updater behavior are unchanged by these interface fixes.
