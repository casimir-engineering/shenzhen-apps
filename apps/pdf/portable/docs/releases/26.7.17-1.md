- Cmd+V in a document searches for the copied text right away
- Select text and press Cmd+F to search for it instantly
- The cursor now shows an I-beam over text and a hand over links
- Select link text by dragging - only a plain click opens the link
- Tear a tab off and slide it right back in one continuous drag
- Drop a torn-off tab directly onto another window's tab bar
- Scroll on the document map to fly through the document
- Update checks now run daily even if you never relaunch

---

### Search

- Paste (Cmd+V, or Edit > Paste) while reading a document to search for the
  clipboard text immediately - no need to click the search field first. When
  a text field is focused, paste behaves as usual.
- Select text in the document and press Cmd+F: the search starts with the
  selection as the query, already selected in the field so typing replaces
  it. Cmd+F without a selection focuses the search field as before.

### Cursor and links

- The cursor now gives standard pointer feedback while reading: an I-beam
  over selectable text, a pointing hand over links (both link annotations
  and plain-text URLs), and the arrow elsewhere - also in unfocused
  windows, without raising them.
- Link text can be selected by dragging: once the mouse moves past a small
  threshold the gesture is a text selection and releasing it never opens
  the link - even if the pointer ends up back where it started. A plain
  click opens the link as before, and during a selection drag the cursor
  stays an I-beam.

### Tabs

- Tearing a tab off and reattaching is now one continuous drag: pull the tab
  out of the bar and slide it back - into its own window or any other
  window's bar - without releasing the mouse. The yellow insertion line
  shows exactly where it will land, just like when reattaching from another
  window. The tab keeps its page, zoom, and search state.
- Releasing a torn-off tab outside a tab bar still opens it in its own
  window, now immediately (the brief slide-back animation is gone).
- Press Escape during a tab drag to cancel it; the tab stays where it was.

### Document map

- Scrolling over the document map now scrolls the map strip itself, and the
  document follows at the strip's scale - a flick traverses the whole
  document, momentum included. When the whole strip fits on screen, the
  gesture still moves the viewport indicator by its own distance.
  Cmd/Ctrl-scroll zoom, click-to-jump, and dragging the viewport are
  unchanged.

### Updater

- The silent daily update check now stays alive in a continuously-running
  app: an hourly background timer plus day-change and wake-from-sleep
  catch-ups re-run the existing once-a-day gate, so a session kept open for
  days (common with session restore) keeps checking. Still at most one
  check per day across all windows, and still controlled by the auto-update
  setting.

### Interface

- Shortcut help: key labels are now vertically centered inside their
  keycaps instead of riding slightly high.

### Fixes

- Hovering over an unfocused window no longer raises it above other
  unfocused windows. The tab-title and comment hover previews were
  re-stacking the whole window as a side effect; they now stay attached to
  their window without changing its z-order. Scrolling unfocused windows
  under the cursor keeps working.
- The update window now shows the release highlights as a proper bulleted
  list instead of one run-together paragraph (visible starting with the
  update after this one).
