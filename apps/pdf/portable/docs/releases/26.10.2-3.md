### Organize your reading

The workspace has slimmer tabs, direct document-tool buttons and more room for the active group. Tab titles hide extensions; the left panel shows the full filename.

Create, name, recolor, reorder or hide groups. Click a group heading to expand or collapse it without changing the document. Drag tabs between groups, or drag a group's handle to another window. Groups, window layouts and reading positions survive a restart.

**Groups** lists every group and searches both group names and document titles. It opens at your current document, with its group expanded.

### Local copies and version history

**Collection** offers to keep local copies while you continue working with the originals. Its document list shows the latest saved copy; older versions belong in the reader's **History** panel.

- **Open original** opens the source file. **Open collection copy** opens the read-only saved copy in a dedicated **Collection Backups** group.
- **History** lets you preview earlier versions and compare with Latest or Previous. Additions are green, removals red, with change markers and linked scrolling.
- If an original disappears, continue reading its saved copy. **Find Document** reconnects it; **Save New Copy As** creates a replacement. Opening a uniquely matching file also reconnects its history.
- Storage is **unlimited by default**. An optional limit removes old versions of least-opened documents first. **Keep forever**, available with a limit, protects the marked document's entire history. Cleanup never deletes originals.

Collection copies stay on this Mac. Successfully entered PDF passwords are remembered in Keychain; saved PDFs remain encrypted and are not indexed as plaintext.

### Open more, paste pictures, save a PDF

Open or drop supported pictures, SVG, e-books, XPS, image archives and modern Office documents alongside PDF and Markdown. Office files open in a reading view.

**Paste an image or a copied image file directly into the reader.** Clipboard pictures show a red unsaved dot. **Save As** offers an image copy or PDF and opens the saved file. Image copies preserve the original image data; pasted images remain available after restarting until you save them.

Plain text and supported source-code files use syntax highlighting. HTML opens as code. **A− / A+**, beside zoom, adjusts text size. **File → Properties** works across formats, including picture dimensions, color information and available camera metadata.

**OCR** now accepts pictures and creates a separate PDF. Whole-document **translation** also accepts text, source code and other supported text documents through a PDF copy. These tools still require their local tool installations and language data.

### Find things faster

**Cmd+K** shows document and group names immediately, then adds text matches. Use `col:` to search Collection only. Find results now include the actual highlighted match and context, indented beneath chapter headings.

Typing outside a text field starts Find. Escape restores the previous panel. **Keyboard Shortcuts** has a searchable list and a highlighted **New!** section.

| Shortcut | Action |
|---|---|
| Cmd+K | Search documents, groups and Collection |
| Cmd+G | Open Groups |
| Cmd+H | Open History |
| Cmd+D | Switch to the previous document; press again to switch back |
| Enter / Cmd+Enter | Next / previous Find result |

### Fixes and responsiveness

Repeated map and group clicks respond consistently. Tab close buttons have hover feedback; panel toggles no longer retain stray backgrounds. Chapters and Comments follow the selected document. Right-click page-copy actions use the page under the pointer.

Context menus, group naming and search avoid unnecessary work. Hidden panels and indexing stay lazy; normal launch adds no indexing pass. The updater's repository, download selection and verification are unchanged.

### For AI agents

CLI and MCP commands can inspect documents, export page previews, navigate to matching passages and manage the same persistent groups as the reader. Group commands use stable IDs and shared YAML state. Source inspection preserves literal text; ordinary launch starts no agent listener or polling loop. See the [agent interface](../agent-interface.md) for commands and coordinate conventions.
