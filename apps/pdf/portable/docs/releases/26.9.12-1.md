- Cmd+I inverts colors, Cmd+Shift+I inverts images with them, Opt+I opens Properties
- OCR no longer gives up on a scanned PDF that is marked as a tagged document
- OCR and Translate move into Shenzhen PDF's own Python environment

---

- **Cmd+I now inverts colors.** It is the toggle reached most often and had the two-handed shortcut. Cmd+Shift+I decides whether images invert with the page, and Opt+I opens Properties, which took Cmd+I before.
- **Keep Image Colors moved to the View menu**, beside the inversion it modifies. It was in Settings, where it read as a preference; it is a per-document choice remembered per file.
- **OCR no longer gives up on a tagged scan.** OCRmyPDF refuses a PDF marked as generated from an office document, naming the flag that would work. A scanned purchase order carrying that mark was rejected before a page was read. Shenzhen PDF now takes that advice and retries once.
- **OCR and Translate move into Shenzhen PDF's own Python environment**, even on a machine that already had them. Only a missing tool used to trigger that, so the installs most exposed to a conda or pyenv setup were the ones it never reached. The move happens in the background and the existing install keeps working until it is done.
