- Open password-protected PDFs with secure retry and cancel
- Open Markdown in native tabs with search, syntax highlighting, print, and PDF export
- EPUB chapter links now navigate to the correct content
- Smoother tab, window, file-manager, and document-map interactions
- New Shenzhen PDF icon aligned with the Shenzhen Files visual family

---

### Text selection

- Double-click selectable PDF text to select a word, or triple-click to select
  its text block or paragraph. Normal drag selection and link clicks keep their
  existing behavior.
- Selection geometry now handles large and imperfect text layers without the
  old fixed rectangle limit. Image-only areas remain honestly unselectable and
  can still be processed with OCR.

### Protected PDFs

- Password-protected PDFs now open through a secure prompt with wrong-password
  retry and cancel support. Passwords remain in process memory only and are
  never written to settings or logs.
- Rendering, search, properties, printing, and file-change handling use the
  authenticated document for the current session. Restricted operations remain
  disabled when the PDF permissions require it.

### Markdown

- Open common Markdown files from tools such as Claude and Obsidian directly in
  Shenzhen PDF tabs. Headings, emphasis, links, quotes, lists, tables, fenced
  code, and local resources use a native read-only presentation.
- Unknown fenced-code languages offer a searchable, keyboard-friendly language
  selector. Document search remains available through the normal Find field.
- Print Markdown through the system print panel or save it as a selectable-text
  A4 portrait PDF. Pagination keeps headings with following content when space
  permits and respects bounded local-resource budgets.

### Tabs, files, and windows

- Cmd+W on macOS and Ctrl+W on Linux close the current tab, including when its
  source file was moved or deleted.
- The tab menu now says `Copy Document`, and detaching a tab restores the
  previously active source tab instead of selecting an unrelated document.
- General settings can reveal files in Finder or Shenzhen Files, with automatic
  Finder fallback when Shenzhen Files is unavailable.
- Double-click empty titlebar or tab-row space to use the native maximize or
  zoom behavior without stealing clicks from tabs and controls.

### Navigation

- EPUB chapter entries now resolve internal destinations and navigate to the
  correct content.
- One discrete mouse-wheel notch over the document map moves no more than one
  page. Precise trackpad scrolling, modifier zoom, and map dragging remain
  smooth.

### Branding

- Shenzhen PDF now uses a blue document marked `深圳` and `PDF` on a warm
  white-to-orange background. The sibling design matches Shenzhen Files while
  remaining distinct in the Dock, Finder, Windows, and Linux launchers.
- Native renditions are generated for every required size instead of upscaling
  the 256 px artwork in macOS packages.

### Release safety

- Release validation now covers native Markdown integration, encrypted-document
  lifecycles, selection interaction, and exact source-size ratchets.
- GitHub assets are uploaded and byte-verified while the release is still a
  draft. Only the verified DMG can be promoted to the public latest release.
