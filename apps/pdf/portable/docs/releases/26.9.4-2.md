- Option + scroll wheel turns pages, wherever the pointer is
- Chapters nest, with arrows and Expand All / Collapse All
- Each document remembers which chapters you left collapsed
- Windows reopen where you left them, on the display you left them on
- Keep Image Colors is remembered per document again

---

- Option + the scroll wheel turns pages, wherever the pointer happens to be --
  the page, the minimap, the sidebar. It behaves like the page arrows: a fitted
  page simply advances, a zoomed page lands on the next page at the same zoom
  and the same position, and Markdown pages too. Paging follows how far the
  wheel turned, so spinning it faster turns more pages, and a trackpad flick's
  momentum is ignored so it cannot run away through the document. Listed in the
  shortcut helper under Pages and View.
- The chapter list nests. A long outline was a flat wall of rows with no way to
  fold a section away. Each parent now carries the usual disclosure arrow —
  pointing down when open, right when collapsed — and children are indented
  under their parent's title. Everything starts expanded, and Expand All /
  Collapse All sit above the list. Identical for a PDF's outline and a Markdown
  document's headings.
- Each document remembers exactly which chapters you left collapsed, across
  relaunches and when a tab is dragged into its own window. A document you have
  never touched opens fully expanded. Edit a document so its structure shifts
  and the sections that moved come back expanded rather than guessing.
- A window reopens exactly where it was left, at the size it was left, on the
  display it was left on. A window closed on a second display came back on the
  main one, and lost a little height on every relaunch: the saved frame was
  correct, but it was handed to the window as though it described the content
  area rather than the whole window, so the window was built one titlebar too
  tall and macOS then moved the oversized window somewhere it fit. A session
  with several windows restores each one to its own display.
- Keep Image Colors is remembered per document again. It became a per-document
  setting in 26.9.3-1, but the choice was lost on every relaunch — a tab's
  saved fields had two writers, and the one that writes the session file never
  learned about it. A datasheet set to keep its colour-coded figures now stays
  that way.
