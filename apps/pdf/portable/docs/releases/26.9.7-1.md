- Links inside Markdown tables can be clicked
- Markdown sheets are numbered: "Page 2 of 10" in the footer
- Dragging a zoomed Markdown page moves it exactly as far as the hand
- Fit Page, Fit Height and Fit Width place the current page, with no gutter showing
- Markdown text no longer wobbles while the page moves
- Copying from Markdown keeps paragraphs, list items, table rows and columns

---

- A fit is not only a zoom any more. Fit Page and Fit Height put the current page exactly in the viewport, top to bottom, and Fit Width fills it edge to edge — for Markdown as for PDF. PDFs also lose the thin strip of background that used to show above a fitted page other than the first.
- Markdown text shimmered while scrolling or dragging: the page landed on fractional pixels and the glyphs were redrawn slightly differently every frame. It now moves in whole pixels and stays crisp.
- Copying a Markdown selection produced one long line. It now reads like the document: a blank line between blocks, list items and table rows on their own lines, table cells separated by tabs, code kept line for line.
- Every Markdown page now carries "Page 2 of 10" right-aligned in its footer — on screen, in Print, Save as PDF and Copy Page alike. It is drawn with the page, not typeset, so it never turns up as a search hit.
- A link in a Markdown table cell looked like a link and did nothing when clicked, and the pointer never changed over it. Cell links now open like any other, with the hand cursor over them — and only when the click actually lands on the link text, not in the empty part of the cell beside it.
- Dragging a Markdown page with the right or middle button moved it faster or slower than the pointer whenever the page was zoomed. It now follows the hand 1:1 at every zoom, like a PDF.
