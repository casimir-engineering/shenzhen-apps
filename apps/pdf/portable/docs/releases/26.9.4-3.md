- Windows come back on the display you left them on, with the right one in front

---

- A window left on a second display could come back on the built-in screen and forget where it belonged. Restoring the exact frame was fixed in 26.9.4-2; this fixes the case that actually loses it. Launching while that display is asleep or unplugged showed the window on the main screen — correct — and then saved that stand-in position over the real one, so one launch without the display forgot it for good. The position you left is now kept until you move or resize the window yourself, and the window returns to its display when it reappears.
- The window you were last using comes back focused. Before, the first window in the session file was, whichever one that happened to be.
- Every other window now opens with the first instead of a launch later: they start together rather than one after the other.
- Markdown page orientation is remembered per file. Turn a document landscape for a wide table or a gantt chart and it reopens that way.
