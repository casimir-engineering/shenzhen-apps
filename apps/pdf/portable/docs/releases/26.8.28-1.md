---

### Markdown reading

- Markdown now opens as native vector A4 sheets in the same reading interface as
  PDFs, with shared tabs, page controls, zoom presets, presentation mode,
  keyboard and pointer navigation, search, and a live document map.
- H1, H2, and H3 headings populate the Chapters panel. Search results and map
  navigation jump to the corresponding paginated sheet without rebuilding the
  document.
- Fenced code is kept as a single semantic block during pagination. A language
  selector above each block supports searchable syntax choices; fences without
  a language start as Plain Text and can be changed directly in the document.
- Text and links remain selectable and interactive. Printing and PDF export use
  vector text and A4 pagination while excluding screen-only controls.

### Documents and selection

- Password-protected PDFs open through a secure retryable prompt. The password
  stays in process memory and authenticated sessions support normal reading,
  search, properties, printing, and file-change handling.
- Double-click selects a word and triple-click selects its text block or
  paragraph. Large or imperfect PDF text layers no longer hit the old fixed
  selection-rectangle limit.
- EPUB chapter entries now resolve internal destinations and navigate to the
  intended content.

### Tabs, files, and windows

- Cmd+W on macOS and Ctrl+W on Linux close the current tab, including when its
  source file was moved or deleted.
- Detaching a tab restores the previously active source tab instead of selecting
  an unrelated document. The tab menu uses the clearer `Copy Document` label.
- General settings can reveal files in Finder or Shenzhen Files, with automatic
  Finder fallback when Shenzhen Files is unavailable.
- Double-click empty titlebar or tab-row space to use native maximize or zoom
  behavior without stealing clicks from tabs and controls.
- One discrete mouse-wheel notch over the minimap moves no more than one page;
  precise trackpad scrolling and direct map dragging stay smooth.

### Launch and responsiveness

- The visible document keeps foreground priority while inactive tabs and
  Markdown page models are prepared lazily in cancellable background work.
- Selecting a tab atomically adopts or cancels its background open operation,
  avoiding duplicate loads and preserving the existing visual and rendering
  quality.
- Expensive Markdown pagination, minimap geometry, and syntax work no longer
  block application activation.

### Branding and release safety

- Shenzhen PDF uses the new blue document marked `深圳` and `PDF` on a warm
  white-to-orange background, with native renditions for every package size.
- Release validation covers Markdown pagination and interaction, encrypted
  documents, selection, launch ownership, updater behavior, and source-size
  ratchets. The direct GitHub release remains signed, notarized, stapled, and
  byte-verified before publication.
