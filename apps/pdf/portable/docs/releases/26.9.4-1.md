- Bold and italic inside diagram labels instead of the raw <b> tags
- Live update for Markdown documents
- Gantt charts use the full width of the page, landscape included

---

- Bold and italic render inside diagram labels. A mermaid node written as
  `USB["<b>USB-C VBUS</b> 5 V"]` drew the tags themselves — seven literal
  characters of markup per pair. Worse, they were measured, so every node was
  sized, wrapped and fitted around text that should not have been there.
  `<b>`, `<strong>`, `<i>` and `<em>` now become real bold and italic runs,
  including nested ones, and the emphasis carries through selection, Cmd+F and
  the exported PDF. Other tags (`<u>`, `<code>`, `<s>`) still render literally.
- A Markdown document reloads when its file changes on disk. PDFs already did;
  Markdown never has. Editing a document in another app now updates the open
  window on its own, within about a second.
- The reload is invisible. It renders the new version in the background and
  swaps it in complete, keeping your scroll position, zoom and selection.
  Nothing blanks, and there is no moment where the page appears at the wrong
  zoom before settling. An unreadable file — deleted, or caught mid-save by an
  editor that truncates first — leaves what is on screen alone rather than
  flashing an error.
- Gantt charts use the width the page offers. A chart was capped at a fixed
  width regardless of paper, so a two-month schedule sat at roughly two-thirds
  of a landscape sheet with the rest blank. It now fills the page and picks a
  finer gridline cadence to match. Other diagram types were checked for the
  same fault and do not have it; a pie chart keeps its fixed size deliberately.
