- Keep local document copies and version history with Collection
- Compare PDF and Markdown revisions, and recover missing originals
- Organize persistent colored tab groups and search everything with Cmd+K

---

### For readers

- **Collection and history (macOS).** Choose at first use whether to keep local, read-only copies and history. Continue opening originals normally. Browse earlier versions and kept milestones in the reader’s persistent History sidebar tab, with a Latest badge on the newest version. Configure exclusions, storage limits and location in Collection. Turning capture off preserves existing history.
- **Collection browser refinement (macOS).** Integrated search shows page thumbnails and highlighted context; clicking a match opens its saved page in the reader. History opens the latest linked original with the reader’s History tab selected; selecting an older version opens its saved copy. Version context menus reveal files in the chosen file explorer. Readable encrypted PDFs receive previews too. Documents and Settings share a left sidebar. Collection opens as a separate app so Cmd+Tab switches between it and the reader. Storage defaults to unlimited; optional cleanup prunes old versions of least-opened documents before final copies, while Keep protects an entire history. Search, history and browsing positions persist. Collection controls align symbols with labels and preserve rounded outlines during search editing. Documents and thumbnails always show one latest saved copy per document. Earlier versions and the Latest pill are confined to History. Opening Collection also handles excluded documents and failed initial captures without crashing during date sorting.
- **Remember encrypted PDF passwords.** Collection keeps successfully entered passwords in this Mac’s Keychain, so originals and matching saved copies can reopen after relaunch. Archived PDFs stay encrypted; passwords are never written into Collection files.
- **Compare revisions.** Inspect PDF and Markdown versions side by side. Removed content is red, additions are green, and change markers help navigate text, images and page changes. Compare with Latest uses the linked original, or the newest saved version if missing. Linked scrolling updates the other pane without reciprocal navigation jumps; scrolling and zoom can also be controlled independently.
- **Recover documents.** Missing originals retain their tabs and offer Find Document or Save New Copy As without an automatic modal dialog. Open a dated archived copy, save a separate editable copy, or locate the original manually or through exact-content matching. Opening a uniquely matching file automatically reconnects a lost original while preserving its history. Older saved copies show a dated toolbar pill; when the original is missing, click the pill to locate it.
- **Search and return.** Cmd+K searches open document names, groups, open text and Collection. Use `col:` for Collection alone. Cmd+Backspace returns to the previous active document, reopening it with its position if necessary; press again to switch back.
- **Tab groups.** Create, rename, recolor and collapse groups. Rounded tinted boundaries identify membership, and stronger selected tabs keep the same readable title color as other tabs. Drag a group's left handle to reorder it or move it to another window. Groups and reading positions survive relaunch. Selecting a tab collapses every other group, including General. Dragged tabs follow the pointer while neighboring tabs make room inside their group. In crowded windows, General tabs yield space to custom groups while the selected document stays visible. Newly created groups stay on the side where you create them, including after relaunch. Labels are centered; click a group header to expand or collapse its tabs without changing the open document, and use the right-click menu to rename it.
- **Vertical side panel.** Icon-labelled Chapters, Comments, Search, History and Group Management entries stack vertically so labels remain readable in narrow panels. Search and Group Management remain available; Markdown omits unsupported Comments. Keyboard navigation, selected-state contrast and rounded focus indicators follow the native controls.
- **Group Management.** Search group names, expand document lists, jump to a group, or show/hide it in the tab bar without closing documents. General can be hidden too. Renaming General makes it a regular group; the next new document creates a fresh General. Sidebar mode, width, visibility, filter, expanded lists, scroll position and group state restore from the existing YAML configuration.
- **Faster browsing and smaller installation.** Tab-group refresh avoids repeated scans in large workspaces, and Collection previews no longer rewrite unchanged library metadata. Closed Group Management and History panels defer their work until shown. History actions remain reachable in short windows. Collection uses a lightweight helper instead of another full reader executable.
- **Markdown layout.** Tables keep short columns readable. Choose paper size, orientation, margins and explicit page breaks in front matter; page-number footers also appear in exports.
- **Markdown sidebar.** Unsupported Comments tabs are hidden, and comment commands stay disabled in Markdown menus.
- **Markdown editing.** Open a source in your preferred editor from its tab or page menu. The chosen editor is remembered and can be changed in Settings.
- **Copy the intended page.** Right-click Copy Page and Copy Page Image use the page under the pointer.
### For AI agents

- **Optional agent access.** The native CLI and MCP adapter inspect PDF and Markdown, export previews, report layout and open a page or highlighted passage. They can also list, create, name, recolor and reorder groups and move tabs, using the same persistent session configuration as the app. Group updates also control visibility; a group-jump command reveals the group and selects its last-used document. Stable IDs and an optional window guard keep commands precise. UI and API changes share the same YAML state, including General’s renamed/default routing. They run only when invoked; see [setup and commands](../agent-interface.md).
