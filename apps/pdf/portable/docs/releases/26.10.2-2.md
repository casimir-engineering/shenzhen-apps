- A compact workspace with persistent tab groups and direct document tools
- Local Collection copies, version history, comparison and missing-file recovery
- Open pictures, e-books, modern Office documents and highlighted source code
- Faster controls, image OCR, updated shortcuts and format-aware properties

---

### For readers

This release brings the macOS workspace and Collection changes together.

- **A compact reader workspace.** Slim document tabs share the title bar, with more space for documents in the expanded group. Other groups remain in the bar when room allows, and a separate Groups button always exposes the full list. Document tools use direct icons with hover help. Side panels align with the top of the workspace; unavailable icons remain readable. Collection and Cmd+K use the same visual style. Tab titles omit extensions, while the left panel shows the complete filename. Long titles retain both ends with a middle ellipsis. Close buttons appear without shifting titles and gain a subtle background on hover.
- **Persistent tab groups.** Create, rename, recolor, hide and reorder groups, including General. New groups immediately offer their suggested name, selected for typing or Enter. Naming and renaming use a compact popover without an opening animation; rapid consecutive header clicks each expand or collapse the group. Click a group header to expand or collapse it without changing the document; rename through its context menu. Drag tabs with visible movement and insertion feedback, or drag a group’s handle to move it to another window. New groups stay where they were created, and crowded tab bars prioritize the active group. Renaming General makes it a regular group; opening another ungrouped document creates a fresh General. Groups, window layouts and reading positions restore from YAML settings.
- **Groups navigation.** Search group names and document titles. Opening Groups expands the current document’s group and scrolls to the document. Group headings remain visible while browsing their documents. Showing or hiding a group does not close its tabs.
- **Collection keeps local copies and history.** A first-use choice controls background capture; the reader continues using original files. Enabling Collection imports reachable recent documents. Identical contents share storage. Documents shows one latest saved copy per document in a single list with small previews; earlier versions live in History. Search stays in Documents and presents highlighted matches with context beside the preview. Clicking a match opens its page, not History. Open original opens the source when available; Open collection copy always opens the saved read-only version, even when its original exists. Copies enter a persistent Collection Backups group with a collection icon; ordinary files opened from that group go to General. Collection has its own Documents and Settings sections and appears separately in Cmd+Tab.
- **One History panel.** A Collection document’s History action opens its latest linked original with the reader’s History panel selected. Saved versions have a Latest badge where appropriate. Earlier copies open read-only and show their date in the toolbar. History remains a regular reader panel when switching between tools. Version context menus can reveal the file in your preferred file explorer.
- **Compare and recover.** Compare a saved version with Latest or Previous in two reader panes. Removed content is red, additions are green, and markers locate changes, including image and page changes. Linked scrolling avoids reciprocal jumps. Missing originals offer Find Document or Save New Copy As without blocking reading. Locate a file manually or search for exact-content matches; opening a uniquely matching file also reconnects its lost history. Restoring a link retains the existing document tab.
- **Clearer storage settings.** Storage is unlimited by default. An optional cap removes the oldest versions of least-opened documents before their final saved copies. Keep forever and Stop keep forever appear only with an applied cap: any marked version protects that document’s entire history from automatic cleanup. Removing a mark deletes nothing immediately. Returning to unlimited storage preserves marks. Per-document Pause/Resume saving controls are removed. Set location and Open location show where copies live, and Apply sits directly under the storage limit. Original files are never deleted by Collection cleanup.
- **Encrypted PDFs stay usable.** Successfully entered passwords are remembered in this Mac’s Keychain for Collection and matching originals. Saved PDFs remain encrypted, receive previews when readable, and are not indexed as plaintext. Passwords are not stored inside Collection files.
- **More files open directly.** Open, Finder Open With and drag-and-drop accept the bundled image formats, SVG, EPUB/MOBI/FB2, XPS, image archives and modern Office files, alongside PDF and Markdown. Multiple dropped files become tabs. Office documents use a reflowed reading view. Additional-format Collection previews and text indexing depend on format support; this does not add Office editing, arbitrary archive browsing or unsupported decoders.
- **Readable text and source code.** Plain text and files for the existing code-block language catalog open as paginated, syntax-highlighted source. HTML/XHTML stays code; Markdown stays formatted and SVG stays an image. Source viewing preserves literal content and does not load referenced assets. A− / A+ sits immediately to the right of zoom and changes text size for Markdown, text and source files. Search, selection, copy, export and Collection use the same text renderer.
- **Search and shortcuts.** Cmd+K shows document and group names immediately, then fills text results asynchronously using lazy caches; `col:` searches Collection only. Find snippets include and highlight the actual match, including wrapped text and regex results. Results are indented beneath chapter headings. Typing outside an input starts Find, and Escape returns to the previous panel. Cmd+G opens Groups; it no longer advances search. Enter advances Find and Cmd+Enter goes to the previous match, including from the document view; Shift+Enter remains an alternate. Keyboard Shortcuts now uses a compact searchable window with aligned keycaps and a highlighted New! section for Groups, History and Previous Document. Cmd+H opens History. Cmd+D returns to the previous document; pressing it again switches back, reopening a closed previous tab with its reading position if needed. Cmd+D replaces the earlier Cmd+Backspace assignment.
- **Properties for every file.** File → Properties (Option+I) and the document context menu work for every selected file, including text and missing originals. Pictures show available pixel dimensions, resolution, color model/profile, bit depth, transparency, orientation, frame count and camera metadata. Text documents show their live page and text statistics; vector images retain vector dimensions. Missing metadata is omitted.
- **OCR and translation across formats.** OCR accepts supported pictures, including multipage images, creates a separate PDF and runs the existing OCR workflow. The image stays unchanged. Whole-document translation works for Markdown, plain text, highlighted source and native text documents such as EPUB and Office files through a PDF rendition. Conversion runs off the UI thread, avoids overwriting existing files and requests an output folder for protected Collection copies. OCR and translation still require their respective local tools and language data.
- **Reading fixes.** The map uses one stable show/hide button so repeated clicks work at the same position. The side-panel toggle no longer retains a colored background after repeated clicks. Chapters and Comments availability follows the selected document; unsupported Markdown Comments are hidden. Right-click Copy Page and Copy Page Image use the page under the pointer. Markdown tables retain readable short columns, authored paper settings and page breaks work with exports, and source-editor choices persist.
- **Less waiting and memory overhead.** Context-menu selection previews process only a small text sample instead of normalizing an entire long selection. Hidden panels defer work until opened. Group refresh avoids repeated workspace scans. Collection preview completion updates visible rows instead of scanning the whole result list. Search caches are bounded, lazy and shared within each process; stale results are cancelled or invalidated. Unchanged previews avoid metadata rewrites, and Collection uses a smaller dedicated helper. Normal launch adds no indexing pass.

### For AI agents

- **Explicit CLI and MCP access.** Inspect PDF, Markdown and supported text/source documents without opening a reader window. Export page previews and report canonical text, geometry and Markdown layout diagnostics. Open a page or highlighted passage using query, context and occurrence. HTML/source inspection preserves literal text. UTF-16 ranges and page-coordinate conventions are documented in the [agent interface](../agent-interface.md).
- **Manage the same groups as the user.** List, create, name, recolor, reorder and show/hide groups; move tabs and jump to a group. Stable IDs and optional window guards keep changes precise. Commands share the app’s persisted YAML state, including General routing, and automated group creation does not show a naming prompt. Saved Collection tabs use the persistent `collection-backups` group identity; ordinary files opened while that group is selected route to General.
- **On-demand operation.** Agent commands and the optional stdio MCP adapter remain explicit entry points. Ordinary reader launch starts no agent listener, polling loop or background inspection. The updater repository, download selection and verification path are unchanged.
