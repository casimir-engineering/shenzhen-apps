---

- **OCR and Translate work whatever Python is on the machine.** They failed outright where conda, pyenv or a virtualenv was set up, because the app passed its own environment to them. The tools now run in an environment Shenzhen PDF controls.
- **Translation installs into its own Python environment**, under Application Support. An install that already works keeps working.
- **OCR now covers every page**, not just the first one it could read. A document that mixes a scanned cover with vector pages comes back fully selectable.
- **OCR fetches the Noto fonts it needs** to draw recognised text, in the background. Chinese, Japanese and Korean documents were the most affected without them.
- **Long OCR sessions stay healthy** — the scan check failed for the rest of the session after roughly 250 documents.
