# Standalone chat window verification

Chat now uses its own titled, closable, minimizable and resizable NSWindow. Cmd+K remains the search palette; Return from an empty search opens the separate chat window. Opening search again leaves chat intact. Native close, File → Close and Escape hide only chat, preserving its transcript and unsent draft for reopening. New chat remains an explicit action. Citation navigation raises the document reader while keeping the conversation open.

Two exclusive pin modes toggle back to ordinary window behavior when selected again. App-only pin raises chat while Shenzhen PDF (including another reader process or the Collection companion) is frontmost, then drops it to normal level when another app activates. App resignation immediately drops the level and reconciles settled workspace activation on the next main-loop turn to tolerate notification order. All-app pin explicitly uses floating level even when the reader is inactive. The mode and frame persist in `chat-window.yaml`; this file and the window are created only after an explicit chat action.

The production-linked context acceptance binary exercises the real search monitor via NSApplication events, then the actual chat window responder dispatch for Return, Shift+Return and Escape. Headless window subclasses suppress ordering only; they retain the native window implementation. Tests verify separate window identity and native style flags, normal default level, independent search/chat views, retained focus and draft, native close and File Close routing, pin activation/deactivation, Collection companion identity, YAML restoration and no eager chat preference creation. Hidden windows cannot receive NSApplication native key-window forwarding without activating an app, so responder dispatch is tested at NSWindow rather than pretending that a hidden app is foreground.

Fresh build and full context acceptance both exited 0: `/tmp/ai-standalone-window-build.log`, `/tmp/ai-standalone-window-run.log`. The same run includes offline provider replies, credential recovery, source citation provenance and cross-document PDF highlighting. No user app was launched, quit or captured. Native helper syntax also passes `-Wall -Wextra -Werror`.
