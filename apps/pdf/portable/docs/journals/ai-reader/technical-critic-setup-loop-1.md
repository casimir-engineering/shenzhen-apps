## Ranked findings

1. **P1 — UTF-16 clipping can crash automatic analysis — fixed and verified.** `SPDFMacAIAnalysisService.mm:145` formerly clipped the 64,000-unit sample with `substringToIndex:` without respecting surrogate boundaries, then does not check JSON serialization before placing the result in a dictionary literal. Valid input consisting of 63,999 ASCII units followed by an emoji and another character produces an invalid lone surrogate; Foundation returns no JSON data and the nil payload makes dictionary construction throw. An independent Foundation probe reproduced the serialization failure. `SPDFMacAIDocumentContext.mm`'s 100,000-unit text/256-unit title bounds and `SPDFMacAILiveTextContext.mm`'s page clipping have the same boundary issue. The repair uses `SPDFAIBoundedText` to clip at a complete composed boundary without expanding the budget, and rejects a nil serialized payload before constructing the request. The production analysis regression covers an emoji across unit 64,000; context regressions cover the oversized combining sequence and exact/zero boundaries. All passed in freshly linked executables.

2. **P2 — Latest-only eligibility can go stale around cache waits and Collection capture — fixed and verified.** `SPDFMacAIAnalysisService.mm:131` originally rechecked latest status only after a provider response. A latest editable revision becoming old during a cache lock wait could return a cache hit without that check. `SPDFMacAIAnalysisIntegration.mm:70` also retained already installed summaries when another revision became latest because its freshness check covered only file/layout identity. Conversely, analysis started before an asynchronous capture promoted an edited old copy could reject it permanently until another open/reflow. The service now rechecks eligibility after the lease. A lazy observer, created for Collection copy analysis, tracks committed local and distributed changes. It captures a generation with requests, rejects stale installation/display, and reschedules the active copy after a change. Root identities are derived from paths and filter unrelated stores before invalidation; render checks use only the captured generation. An initial repair was flagged for process-local events, work after opt-out, and unscoped distributed events. Final regressions cover a real second-process broadcast, unrelated temporary stores, stale display/install, a latest-to-old transition during the cache lease, and no candidate work after opt-out. All passed. Automatic rescheduling after capture is additionally source-reviewed.

3. **P2 — Default-on chat bypassed setup/connection gates, and Disconnect did not synchronously cancel it — repaired.** `SPDFMacAIIntegration.mm:93` now checks setup revision and connection configuration before the Keychain lookup. `SPDFMacAISettingsIntegration.mm:145` cancels chat against the effective settings gate, so Disconnect does not wait for a distributed notification. Automatic analysis receives the same effective gate.

4. **P2 — Wizard completion had migration and process races — repaired.** `SPDFMacAISettingsIntegration.mm:158` adopts an existing Keychain credential, persists completion while still holding the onboarding lock, then releases it and always broadcasts the committed settings. First-paint presentation rereads completion after acquiring the lock. This closes the prior duplicate-wizard race, silent disabling for existing credentials, and missing broadcast when a Collection choice already existed. Closing early still leaves setup incomplete; saved wizard progress resumes it.

5. **P2 — Storage UI could promise a different policy from the backend — repaired.** Dynamic policy is fixed at the requested 80%; its former editable percentage was misleading because the backend always used 80. A fresh switch to Static now initializes a positive 10 GiB limit rather than persisting zero/unlimited. The host validates positive finite values. The native controller now rejects invalid numeric input instead of turning a typo into a small budget that could later evict saved history.

6. **P2 — Setup omitted disclosure of the newly default-on automatic upload — repaired.** `SPDFMacUnifiedSettings.mm` now explains on the wizard's AI page that completing setup sends opened document text for summaries/chapters and consumes account credits. The disclosure appears before leaving the page, while connection and completed setup still gate requests.

7. **P3 — Asynchronous state changes left visible controls stale — repaired and verified.** Disconnect from an initially connected AI page did not create the manual-key alternative; successful manual connection left obsolete key-entry controls visible. Collection relocation and budget updates did not refresh their visible text. The final controller rebuilds connection controls only on a real connected-state transition, preserving drafts on status-only updates, and updates Collection labels in place. Fresh native controller tests verify both connection directions, draft preservation, and label updates. The Unlimited budget description now says “No storage limit” instead of zero bytes.

## Final native-path follow-up

The parent's final native interaction found a **P2 reentrancy defect**: after an invalid Static field, changing to Dynamic and quickly continuing could show the Step 3 footer with the Collection body. `SPDFMacUnifiedSettings.mm:341` emitted a synchronous host callback and then unconditionally rebuilt Collection, even if that callback had processed Continue and advanced to AI.

The repaired handler captures a section generation before the callback. `selectSection:` increments that generation, and the trailing Collection rebuild runs only when both generation and active section still match. The regression deliberately performs Continue inside the settings callback, then asserts step 3, the AI model control present, and Collection controls absent. The owner's pre-fix run fails this exact assertion (`/tmp/sz-settings-reentrant-before.log`); its repaired run passes. The critic independently reran the freshly compiled native settings executable: **exit 0**, `/tmp/spdf-critic-setup-reentrant-final.log`. `git diff --check` also passes. This P2 is closed; technical, visual craft, and usability grades remain **9.0/10**. No additional app interaction was performed by the critic.
